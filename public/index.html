Markdown 与 Codex 会话，一键生成短链

短笺（Notelet）用于快速发布 Markdown 文档和结构化 Codex 会话。无需注册，可设置链接有效期，并保留图片、代码与图表的阅读体验。

所见即所得，也保留源码

可视化编辑与 Markdown 源码自由切换，支持标题、列表、表格、代码块和粘贴图片。

短链与有效期

自动生成易分享的短链接，或自定义路径；可设置 1 小时到永久有效。

代码与图表

常见编程语言自动高亮，Mermaid 流程图、时序图、状态图等直接渲染。

常见问题

发布短笺需要注册账号吗？

不需要。打开页面即可编辑和发布，请不要上传敏感或私密信息。

过期后内容会怎样？

带有效期的文档和关联图片在到期后无法访问，并由后台清理。

短笺是否开源？

是。源代码采用 MIT 许可证，可在 GitHub 查看、部署和改进。
